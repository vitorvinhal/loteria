CHANGELOG TÉCNICO - Loterias CAIXA Omega

RESUMO DA VERSÃO
-----------------
Limite de geração ampliado para 250 jogos, camuflagem administrativa por
usuário (Super Sete + Lotofácil), avatar corrigido para todos os usuários,
sincronização sem limite fixo, filtros e UI aprimorados na comparação,

===============================================================================
MUDANÇAS DETALHADAS
===============================================================================

1. NOVO: Limite de Geração 250 Jogos
   Arquivos: src/app/gerar/[loteria]/page.tsx, src/app/api/gerar/[loteria]/route.ts
   - Input numérico (+/-) agora aceita 1 até 250 jogos.
   - Validação na API aceita até 250 jogos por geração.

2. NOVO: Camuflagem/Ilusão por Usuário
   Migração: database/migration_perfil_foto.sql
   - Coluna `camuflagem_ativa BOOLEAN DEFAULT FALSE` em perfil_foto.
   - API admin: /api/admin/camuflagem/[userId] (GET/POST toggle).
   - Geração: quando camuflagem_ativa, quantidade >= 30 e loteria
     Supersete/Lotofácil, insere até 3 jogos fictícios com score 100.

3. CORREÇÃO: Avatar para todos os usuários
   Arquivos: src/app/api/gerar/[loteria]/route.ts, src/app/api/lotes/route.ts
   - Avatar passa a ser buscado da tabela perfil_foto (não só do metadata),
     garantindo que todo usuário autenticado exiba sua foto no histórico.

4. CORREÇÃO: Sincronização sem limite fixo
   Arquivos: src/app/api/sync/batch-todas/route.ts, src/app/sincronizar/page.tsx
   - Removido Math.min(1000, ...) no batch-todas.
   - Botão "Sincronizar Todas" agora itera loteria por loteria (pequenas
     requests, respeitando timeout do Vercel).

5. MELHORIA: Comparação de Lotes
   Arquivos: src/app/comparar/page.tsx, src/app/historico/jogos/page.tsx
   - Jogos ordenados do maior para o menor percentual de acertos.
   - Resumo estatístico com contagem por faixa de acertos (barra + qtd).
   - Simulação de premiação com dados oficiais do concurso:
     subtotais por faixa e total de premiação líquida.
   - Filtros por período (tudo/7/30 dias) e busca por nome/autor.
   - Exibição do nome do lote na listagem do histórico.
